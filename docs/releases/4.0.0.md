First release of **CaliGo**, formerly MIOCard: cards, stops and lines of the MIO in Cali.

> Unofficial app, not affiliated with Metro Cali S.A. The data comes from its public services and may not be accurate.

## Coming from MIOCard

CaliGo is a new Android app (another name and another signature), so it does not install over MIOCard. To bring your data along:

1. In **MIOCard**: Settings > **Export data**, and save the file.
2. Install **CaliGo** and go to Settings > **Import data** with that file.
3. Once everything is in place, uninstall MIOCard.

From this release on, new versions install over the previous one and keep everything.

## What's new

- **New design**, cleaner, in light and dark themes.
- **Lines**: each line's route on the map, its live buses going each way, and its hours.
- **Favorite stops**: choose which lines each one shows and which ones appear on the home screen, and order them by dragging or by proximity.
- **Stop details** with a button to refresh the arrivals on the spot.
- **Cards**: the balance refreshes on opening the app (can be turned off), and cards can be reordered.
- **Cleaner map**, without the base map's stops and shops, with an optional dark map and stop search from the home screen.
- **Check for updates** in Settings > About.
- Uses less data and goes easy on the public services it reads.

## Installation

1. Download the **arm64-v8a** APK (any phone from the last decade). Use **armeabi-v7a** only on old 32-bit phones.
2. Allow installing apps from unknown sources when Android asks.
3. Open the downloaded file to install it.
